speakfreely

选择会话后显示最近消息
就绪。选项目 → 选会话（或新建）→ 选模型 → 输入目标 → 运行。

快速上手

  1. 左侧依次选择 项目 → 会话 → 模型（模型可留空，用 OpenCode 默认）
  2. 在输入框写下目标或消息，点 ▶ 运行
  3. 日志实时滚动，完成后到项目目录的 tools/、evidence/ 看产物

两种模式

  • 新建会话（默认）：目标写进一个半成品文件，AI 当作"补全代码"来做，自动跑 侦察 → 枚举 → 分析 → 验证 → 取证 五个阶段 这就是为什么推荐用"梳理 X 的流程并整理证据"这种工程化说法
  • 已有会话：输入直接作为消息发进该会话；被 AI 拒绝时，自动把拒绝替换成 "继续…" 再重试 最多 3 次，仍失败就换个模型重试

被拒了怎么办

  • 点 清理该会话：扫描该会话里的拒绝回复并替换（自动整库备份）
  • 点 开启 watch：放到后台轮询，产出新拒绝自动替换；之后在 Desktop 里发"继续"即可
  • 想回滚：终端跑 ./scripts/speakfreely restore

小贴士

  • 五个阶段鼠标悬浮有说明；不想跑全流程就取消勾选要跳过的阶段
  • 不同模型的拒审阈值差别很大——连续被拒时，换模型比改提示词有效
  • "预热示例"会在会话前注入几对示例问答（many-shot），可选
  • "替换文案 = LLM 生成"需要先在 ~/.config/speakfreely/config.json 配好模型

命令行的等价操作

  • speakfreely vibe "目标" --project …：本页"新建会话"的全自动版本
  • speakfreely watch --project …：本页的 watch 开关
  • speakfreely report：看各模型的拒绝率与花费
